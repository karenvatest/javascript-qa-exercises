# 🧪 JavaScript QA Exercises

Repositorio de ejercicios prácticos de **JavaScript aplicado a QA Automation**.

El objetivo es fortalecer los fundamentos de JavaScript mientras se desarrollan habilidades útiles para la automatización de pruebas: validación de datos, búsqueda, filtrado, generación de test data, assertions y ejecución de pruebas.

---

## 🎯 Objetivos

- 🧠 Fortalecer fundamentos de JavaScript.
- 🧪 Aplicar programación a escenarios de QA.
- 🔍 Trabajar con datos de prueba.
- ✅ Practicar validaciones y assertions.
- 🚀 Construir bases para QA Automation.

---

## 📚 Ejercicios

### 👤 01 — Crear usuarios

**Objetivo:** Crear usuarios mediante objetos y funciones para generar datos estructurados que puedan utilizarse como *test data*.

**Conceptos:** `Objects` · `Arrays` · `Functions` · `Parameters`

---

### 🔐 02 — Validar usuarios

**Objetivo:** Validar los datos de un usuario mediante reglas definidas y comprobar escenarios con información válida e inválida.

**Conceptos:** `Conditions` · `Logical Operators` · `Validation` · `Positive/Negative Testing`

---

### 🔎 03 — Filtrar usuarios

**Objetivo:** Obtener usuarios que cumplan determinados criterios, como rol o estado, utilizando filtros sobre un conjunto de datos.

**Conceptos:** `filter()` · `Conditions` · `Data Filtering`

---

### 🔍 04 — Buscar usuarios

**Objetivo:** Encontrar un usuario específico y manejar correctamente el escenario en el que no existe un resultado.

**Conceptos:** `find()` · `Search Logic` · `null` · `Result Validation`

---

### ⚖️ 05 — Comparar y validar

**Objetivo:** Comparar resultados esperados contra resultados actuales para determinar si una prueba cumple con las condiciones definidas.

**Conceptos:** `Expected vs. Actual` · `Assertions` · `PASS/FAIL`

---

### 🧬 06 — Generar test data

**Objetivo:** Generar múltiples usuarios automáticamente para crear datos de prueba de forma dinámica y reutilizable.

**Conceptos:** `Functions` · `Loops` · `Arrays` · `Dynamic Data`

---

### 🛒 07 — Filtrar productos

**Objetivo:** Filtrar productos utilizando diferentes condiciones, como precio y disponibilidad, y validar que los resultados sean los esperados.

**Conceptos:** `filter()` · `Multiple Conditions` · `Expected vs. Actual`

---

### 🔎 08 — Buscar productos

**Objetivo:** Implementar búsquedas exactas y parciales, incluyendo escenarios donde no existen coincidencias.

**Conceptos:** `find()` · `filter()` · `includes()` · `Case-Insensitive Search`

---

### 🛍️ 09 — Validar carrito

**Objetivo:** Comprobar que todos los productos de un carrito tengan valores válidos para precio y cantidad.

**Conceptos:** `every()` · `Collection Validation` · `PASS/FAIL`

---

### 🧪 10 — Mini Test Runner

**Objetivo:** Crear una lógica básica para ejecutar pruebas y reportar automáticamente si cada prueba pasa o falla.

**Conceptos:** `Callbacks` · `Test Execution` · `Assertions` · `Test Reporting`

---
